## ✨ Features

- **Three pillars on display** — LAN/WAN/SD-WAN · Firewall Security · AI-Driven Automation
- **Dark purple theme** — deep `#050508` background, `#a855f7` → `#ec4899` gradient accent
- **Animated network canvas** — live node graph in the hero background
- **Typewriter title** — cycles through *Network Engineer → Network Security Engineer → AI-Driven Network Automator → CCNP ENCOR Certified*
- **Floating stat chips** — Vibe Coder · Speed Cuber · Technoholic
- **Certifications showcase** — CCNP ENCOR (350-401) · CompTIA Network+ (N10-006)
- **8 automation projects** — split across CLI · API · GenAI/LLM categories
- **Fully responsive** — desktop two-column grid, mobile stacked with portrait photo
- **Scroll animations** — timeline, project, certification, and education cards animate in on scroll
- **Zero dependencies** — pure HTML / CSS / JS, no frameworks
